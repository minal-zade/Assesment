# 🧑‍💻 SBM Assessment – Django + Supabase + REST API

## 📘 Overview

This is a simple web application built using **Django REST Framework** and **Supabase PostgreSQL**.  
It demonstrates:

- CRUD (Create, Read, Update, Delete) operations on Employee data
- REST API endpoints
- A simple HTML UI for managing employees
- Deployment using **Render**

---

## ⚙️ Tech Stack

- **Backend:** Python (Django, DRF)
- **Database:** Supabase PostgreSQL
- **Frontend:** Simple HTML Template
- **Version Control:** Git + GitHub

---

## 🚀 Features

✅ Create, Read, Update, Delete Employees  
✅ REST API with Django REST Framework  
✅ HTML UI for viewing and managing Employees  
✅ Connected with Supabase PostgreSQL  
✅ API integration-ready structure

---

## Run the project

Cmd:- python manage.py runserver
